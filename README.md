```mermaid
flowchart LR
    DEV["👨‍💻 Development"]
    GIT["Git / GitHub"]
    CI["CI Pipeline"]
    TEST["Test & Quality"]
    BUILD["Container Build"]
    REG["Container Registry"]
    CD["CD / GitOps"]
    K8S["Kubernetes"]
    OBS["Observability"]

    DEV --> GIT
    GIT --> CI
    CI --> TEST
    TEST --> BUILD
    BUILD --> REG
    REG --> CD
    CD --> K8S
    K8S --> OBS

    OBS -. Feedback .-> DEV
```

```text

  │
  ▼

          ▼
       CD / GitOps

          ├── Networking
          └── Scaling
                │
                ▼
        Prometheus · Loki
                │
                ▼
             Grafana
```
